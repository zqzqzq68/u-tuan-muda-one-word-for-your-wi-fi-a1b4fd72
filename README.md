One Word for Your Wi-Fi: a program that scores candidate words against the judge's brief — on-subject, funny at once, true to how home Wi-Fi behaves, fresh angle, instantly readable — and writes the winning word, **Diva**, to `/output/entry.txt`. Wi-Fi is a diva: it only performs when the conditions are perfect and storms off mid-performance the moment anything displeases it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

The program writes exactly one word (`Diva`, 4 bytes, no trailing newline) and reads it back to verify the file on disk before exiting. Two runs produce byte-identical output.
